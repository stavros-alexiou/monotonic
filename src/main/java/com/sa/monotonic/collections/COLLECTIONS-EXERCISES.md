# Collections in Java SE 21 - 20 exercises

Unzip into the root of `sa-experiments`. It adds the package `com.sa.training.collections`
(nothing existing is touched).

How each exercise works:
1. Read the class Javadoc and answer the Q/A questions in it.
2. Fill in every `PREDICT_...` constant (`"???"` / `null`) BEFORE running.
3. Replace every `Check.todo()` with your implementation.
4. Run the class's `main()` -> aim for all `[PASS]`.

`RunAllExercises` runs all 20 and prints a grand total.
`[TODO]` = not done yet, `[FAIL]` = wrong, `[PASS]` = done.
Ex03 (Team) and Ex04 (Money) start as [FAIL]: their compact constructors are empty on purpose.
