# Streams & lambda expressions - 20 exercises

Unzip into the root of `sa-experiments`. It adds the package `com.sa.training.streams`
(self-contained: its own Check helper and Shop sample data; nothing existing is touched).

Per exercise:
1. Read the class Javadoc, answer the Q/A questions in it.
2. Fill in every `PREDICT_...` constant (`"???"` / `null`) BEFORE running.
3. Replace every `Check.todo()` with your implementation.
4. Run its `main()` until everything is `[PASS]`.

`RunAllStreamExercises` runs all 20 with a grand total.
Number formatting in Ex20: use `String.format(Locale.ROOT, ...)` (a Greek locale prints 47,1).
